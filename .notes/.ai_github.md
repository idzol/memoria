# Memory Dungeon - Recent Changes (AI Summary)

## Highlights
- Added scene and input consistency across combat, event, map, and menu flows.
- Expanded settings and display handling for real-time updates.
- Improved battle/event visual layout and animation behavior.
- Refined Battle Map readability, visibility rules, and navigation.
- Standardized character stat icon language across key UI screens.

## UI and Menu
- In-game menu:
  - `Esc` (`ui_cancel`) now consistently resumes gameplay (same behavior as `Resume`).
  - Added keyboard navigation/selection behavior improvements.
  - Added selection-outline styling fixes (single selected item, no duplicate outlines).
  - Added input delay guard on confirmation dialogs to prevent instant accidental acceptance.
  - Added settings overlay launch path from `Settings`.
- Main menu and save-list interactions:
  - Keyboard navigation/selection improvements.
  - Modal focus/interaction improvements for save list popup.

## Settings and Audio
- Settings overlay:
  - Added `Esc` to save/close overlay.
  - Expanded resolution list for testing.
  - Resolution change now forced through `DisplayServer` for immediate OS-level updates.
  - OptionButton visual behavior updated to outline-focused style (no selection shading).
  - Real-time display/audio setting wiring improvements.
- Audio:
  - Real-time master/music/SFX integration flow tightened with AudioManager.

## Battle Scene and Combat
- Scene behavior:
  - `Esc` exit-to-map now blocked in uncleared battle rooms.
  - Added enemy-facing orientation updates and floor/sprite positioning consistency work.
- Combat logic:
  - Armor card behavior integrated for temporary defense and reset-on-hit behavior.
  - Trap interaction updated to respect armor logic.
- Combat visuals:
  - Added action-sheet animation switching:
    - Player attack uses `attack_sheet`.
    - Player hit uses `defend_sheet`.
    - Enemy attack uses `attack_sheet`.
    - Enemy hit uses `defend_sheet`.
  - Added temporary animation-to-idle restoration flow with tokenized animation control to avoid loop conflicts.

## Event Scene
- Applied BattleScene-aligned environment logic:
  - Floor texture load/path/fit behavior aligned.
  - Viewport resize handling now updates floor fit and sprite placement.
  - Player and NPC positioning aligned to battle layout rules.
  - Player spritesheet setup aligned with battle flow.
  - NPC facing direction updated to match encounter presentation.

## Battle Map
- Visual and layout updates:
  - Added repeating tiled background (`res://assets/maps/backgrounds/map_battle_background.png`).
  - Removed default node border visibility; border shown only for selected node.
  - Increased node spacing and added deterministic per-node `(x, y)` jitter.
  - Reworked connection drawing pass so dotted lines are drawn after all node positions are known.
- Visibility model updates:
  - Reworked node visibility to focus on visited/current/adjacent-connected nodes.
  - Ensured connected-line endpoints are visible when needed.
  - Removed heavy past-node black shading for better readability.
- Scrolling:
  - Constrained map content width/scrolling to currently visible node ranges.
- Input conflict fix:
  - Resolved `ui_cancel` conflict between BattleMap and InGameMenu by consuming handled input and guarding double-processing.
