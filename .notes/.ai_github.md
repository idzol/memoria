## Release Notes For This Branch

### Added
- New intro cinematic flow in `IntroCinematic`, replacing the separate intro credits scene.
- `DebugWorldMapTiles` scene and script for previewing one hex tile per room with room-specific map art.
- `WorldMapTileBackgroundSettings.gd` plus generated `data/map/worldmap_tile_background_scales.json` for per-room map icon scale and offset overrides.
- `scripts/update_worldmap_tile_background_scales.py` to analyze room map art and write/update world map background settings.
- Hex-mask rendering for world map hexes via `features/map/HexMask.gdshader`.
- Tutorial biome world-map background asset wiring through `MapAssetData` / `map_data.tres`.
- Additional localized text for world map, dialog, and character screen restrictions.

### Changed
- `WorldMapUI` was heavily reworked around a hex-based story map presentation:
  - proportional zoom and drag-panning
  - top-right zoom controls
  - tiled biome background that pans and zooms with the map
  - direct-launch biome picker for F6 scene testing
  - current/adjacent/completed visibility logic
  - completed room persistence and fog-of-war presentation
  - current-room adjacency line rendering
  - stronger layout padding and bottom safe area above the run log
- `MapNode` now supports:
  - per-room icon scaling and offsets
  - masked hex room art
  - hex overlays/borders rendered above room art
  - thicker hex outlines
  - removal of the default square keyboard-focus outline
- Story flow was streamlined:
  - `StoryCutscene` and `StoryChapterSequence` can skip on any key or mouse press
  - story-line tiles go directly to the biome world map instead of opening a story chapter summary
  - story map tile sizing was aligned with story chapter tiles
  - death/end-day return flow now routes back to `StoryLine`
- `BattleScene`, `EventScene`, and `LoreScene` narration handling was expanded so dialog overlays can advance, collapse, or dismiss on broad player input.
- `BattleScene` top-bar handling was standardized, with avatar/menu access restored and cleared-room UI behavior improved.
- `CharacterScreen` now restricts deck/item changes to biome home nodes only, showing a toast elsewhere.
- `MapGenerator` / `BattleMapGenerator` were updated for safer direct invocation and improved room fallback handling.

### Fixed
- Battle-mode resource spam from broken `_default` room assets (`the_core`, `swamp`, `abyss`, `void`) and repeated fallback loading.
- Generator `process_frame` crashes when map generators are used off-tree during direct scene testing.
- World map background / node scaling drift across zoom and viewport changes.
- Hex background masking alignment against the actual hex outline.
- Revisit/backtrack handling in story mode so same-run returns can trigger the boss/backtrack event and reset correctly on new runs.
- Cleared-room narrator overlays such as “You see nothing further of note here.” now dismiss correctly on any key or click.
